# 线性代数与解析几何 · 交互讲义（第 1–4 章）

依据 **代万基、廉庆荣、王颖等编《线性代数与解析几何》**（大连理工大学，2012）制作的可交互
**定理—题目双向索引**。支持电脑、平板和手机浏览器。

> 范围：第 1 章 矩阵及其初等变换、第 2 章 方阵的行列式、第 3 章 可逆矩阵及 n×n 型线性方程组、
> 第 4 章 空间的平面与直线。共 **16 节、334 个条目**。

## 主要功能

- **章节目录**：左侧按“章 → 节 → 小节”跳转，记录已访问小节。
- **双搜索框**：顶部“定理”与“题目”两个独立搜索框，实时下拉预览；回车进入完整结果页，
  支持按“定理 / 定义”“题目”分栏查看。
- **定理库**：按章节、类型（定义/定理/推论/引理/性质/公式/附录）筛选，显示每条定理
  “可应对多少题”。
- **题库**：按章节、题型（例题/习题/思考题/提高题）筛选，显示每道题“涉及多少定理”。
- **双向关联**：定理详情页列出“可应对的题目”，按题型分组；题目详情页列出“涉及的定理”。
  未标注直接关联的条目会自动给出“同节条目”作为兜底。
- **专题复习**：按知识主题（行列式、逆矩阵、向量积、平面方程……）把定理与题目重新聚合。
- **教材原页**：每条详情右侧显示对应教材页缩略图，点击放大；可跳转 PDF 原页。
- **收藏 / 最近浏览 / 深浅色 / 平板适配**：收藏与记录保存在本机浏览器。
- **离线可用**：直接双击 `index.html` 即可，无需联网、无需服务器。

## 在平板上使用（推荐）

1. 双击本目录里的 **`启动网站.bat`**。
2. 电脑会自动打开“在平板上打开”页面，上面有二维码和地址，例如 `http://10.15.26.198:8081/`。
3. 让平板连接**与电脑相同的 Wi-Fi**，用相机扫描二维码即可。
4. 在平板浏览器菜单中选择“添加到主屏幕”，之后可以像 App 一样打开。

> 网站运行期间请保持命令行窗口开启；关闭窗口或按 `Ctrl+C` 即停止。
> 电脑重启、切换 Wi-Fi 后 IP 可能变化，重新双击 `启动网站.bat` 即可，二维码会自动更新。
> 端口使用 **8081**，避免与“数分交互讲义”的 8080 冲突。

### 如果平板打不开

- 确认电脑和平板在同一个 Wi-Fi，且没有连接不同的访客网络。
- 学校/单位 Wi-Fi 可能开启“客户端隔离”，设备之间不能互访。此时可以：
  - 用电脑开启**移动热点**，平板连接该热点，然后重新运行 `启动网站.bat`；
  - 或部署到公网（需要可用的托管方式/账号）。
- 防火墙：本机已有 `python.exe` 的入站放行规则，一般无需处理；如果仍被拦截，右键
  `启动网站.bat` → **以管理员身份运行**。

### 不用启动脚本时

在本目录运行：

```bash
python -m http.server 8081 --bind 0.0.0.0
```

电脑访问 `http://localhost:8081/`，平板访问 `http://电脑局域网IP:8081/`。

## 制作说明与边界

- 教材是扫描版，文字、公式由人工逐页转录为 LaTeX；全部公式已用 KaTeX 校验通过，
  但仍可能有转写偏差，**以教材原页为准**（详情页可一键查看原页）。
- 例题保留教材解答；习题、思考题、提高题只录题干，`思路提示` 为编者补充的简短提示，
  不替代完整解答。
- 定理—题目关联来自教材编号、解题步骤与人工复核；转录时标注为“涉及/可应对”，
  不是唯一解法，也不保证穷尽所有联系。
- 少数教材未编号的定义/性质/公式使用描述性名称（如“性质（矩阵乘法的运算律）”），
  在列表中会截断显示，悬停可看全称。
- 已标注“转录存疑”的条目会显示红色徽标（如个别教材印刷笔误），保留原文并加注说明。
- 教材内容版权归原作者及出版方所有。本页仅作为个人学习用途的索引与阅读辅助，
  不替代原书。
